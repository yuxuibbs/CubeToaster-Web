Instructions

  • Fill out the form with the information you want to print on a scoresheet.
  • After hitting submit, it will create an HTML file that consists of one big scoresheet per page. It will not look like what you want until you try to print the page.
  • Print with 4 pages per sheet.

Notes

  • You can inspect and change the font size in CSS if you want to make text bigger/smaller.
  • Competitor ID's are not currently supported but there is a space for it to the left of the event name.
  • Entering only ",,," (3 commas) in the last box will give you 4 blank scoresheets (1 sheet of blank scoresheets).

Only the list of names is required.
